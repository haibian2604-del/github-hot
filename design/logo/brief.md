# GitHub Hot Logo brief

用途：GitHub 热门仓库浏览工具；中文开发者，快速扫读与发现开源项目。关键词：鲜明、精确、开放、克制。保留 GitHub Hot 名称与深墨/信号黄主色；替换页头箭头和仍为旧火焰的 app/icon.svg，选定方向后统一落地。不使用 GitHub 猫形、普通增长箭头或多色渐变。网站字标仍为现有排版，不重新绘制整套字体。

## 概念探索与筛选
评分顺序：清晰/辨识/简洁/相关/小尺寸，每项5分。
1. 阶梯H：H横梁上移一个台阶，把Hot与排行交汇。5/4/5/5/5，入选A。
2. 折面火种：切角轮廓与负形火芯，呼应Hot。5/3/4/5/4，入选B。
3. 开放汇流：两条相向开放路径围出中心留白。4/4/5/4/5，入选C。
4. GH连字：两字母挤占图标空间，3/3/3/5/2。
5. 三阶柱形：清楚但近似统计图标，5/1/5/4/5。
6. 榜单书签：过于直接解释功能，5/2/4/4/4。
7. 仓库盒子：容易与包管理产品混淆，4/2/4/3/4。
8. 正负号火花：像编辑器功能图标，3/3/4/3/4。
9. 上升箭头：保留当前图标却缺乏独立性，5/1/5/4/5。
10. 温度刻度：容易被理解为天气或监控，4/3/4/2/4。

研究：本地developer-tools样本295枚，多见抽象、象形、蓝色及容器；研究Framer、Pagekit、Kotlin的几何构造，不描摹。检索火焰题材确认需避开Lit的叠层平行四边形和PyTorch的开放圆环。

构造：256方画布，整数网格。A为单一实心H轮廓、48宽竖干、横梁上移24；B为尖角外轮廓与圆弧底部，中心菱形留白；C为互相错位的直角开放路径。黑白先行，候选阶段不制作完整品牌套件。
