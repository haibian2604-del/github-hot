# GitHub Hot 页面重构

用户确认整体重设计、保留信息并减少重复；选择「深墨橙 · 工程索引」和「黄黑导视」融合。以用户文字选择为准，代码实现。

## 设计
面向开发者快速扫读热门仓库。深墨色紧凑页头、暖白内容区；黄色用于筛选选中态，橙色用于周期增长。平面材质、清晰字阶、精确对齐，不使用玻璃、阴影或大幅营销标题。页头站名和当前榜单构成首屏，不添加虚构指标或宣传内容。

筛选工具栏维持吸顶与原生下拉；仓库采用舒适双列、窄屏单列，排名、名称、描述、语言、Stars、Forks、增量、贡献者保留。每项周期仅保留辅助技术可访问文案，视觉只出现 +增长；周期集中在摘要说明。来源集中在页脚。骨架、错误、空态沿用同一视觉系统。亮暗主题、外链、缓存、预热、URL 和前进后退行为保留，不修改接口与数据层。

## 方案比较
单独工程索引：清楚但选中态不够鲜明。单独黄黑导视：大面积黄会抢占仓库信息。用户选择融合，黄色限于当前选择；布局沿用标准列表和筛选，不模拟航站楼设施。
